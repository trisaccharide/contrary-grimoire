# The Contrary Grimoire: Light Magic

A science spellbook Doodle by Mina.

## Run
Download index.html and open it in a modern browser. All HTML, CSS, and JavaScript are embedded in this one file. No installation or account is required for the downloaded version.

## Play
Explore two different mixtures, discover yellow/cyan/magenta recipes, then predict and test white light. Download your field notes before leaving the page.

## Science
This is simplified additive RGB mixing, not paint mixing or calibrated optics. Slider settings represent screen channels, not physical power. See the University of Arizona outreach reference: https://wp.optics.arizona.edu/oscoutreach/color-mixing/

AI helped implement and test this prototype. The write-up distinguishes actual design decisions, AI implementation, and personal reflection to complete after playtesting.
